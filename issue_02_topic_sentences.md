# Issue: Improve Topic Sentence Quality

**Labels:** academic-writing, structure

## Context
Each paragraph should begin with a clear topic sentence that signals what the paragraph will cover.

## Acceptance Criteria
- [ ] Every paragraph has a topic sentence
- [ ] Topic sentences preview the paragraph's main point
- [ ] Topic sentences use strong, active verbs
- [ ] No paragraph starts with a citation or transition phrase
