# Issue: Citation Format Consistency

**Labels:** academic-writing, citations

## Context
Inconsistent citation formatting distracts readers and weakens academic credibility.

## Acceptance Criteria
- [ ] All in-text citations follow the same format (Author, Year)
- [ ] All sources in text appear in References
- [ ] All references appear in text
- [ ] No citation fragments (partial citations that don't match references)

Reference: Genskow & Shapiro style guide - Citation Standards section
