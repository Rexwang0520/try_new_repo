# Issue: Data Visualization Standards

**Labels:** academic-writing, data-viz

## Context
Figures and tables should be clear, self-contained, and enhance the argument.

## Acceptance Criteria
- [ ] All figures/tables have numbered titles (e.g., "Figure 1: Title")
- [ ] All axes are labeled clearly
- [ ] All figures/tables are referenced in the text before they appear
- [ ] Source notes included for all data
- [ ] No figure/table exceeds one page
