# Issue: Abstract and Executive Summary Standards

**Labels:** academic-writing, abstract

## Context
The abstract should be a standalone summary that allows readers to decide whether to read the full paper.

## Acceptance Criteria
- [ ] Abstract is 150-250 words
- [ ] Abstract includes: context, objective, method, key findings, implication
- [ ] No citations in abstract
- [ ] No new information in abstract (only what is in the paper)
- [ ] Written in past tense
